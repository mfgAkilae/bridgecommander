Star Trek: Bridge Commander 1.1 · multiplayer

bcmpfix: what changed, before and after

Every fix from v1.0.0 to v1.7.4, measured in Windows Sandbox with simulated network conditions (mostly 60 ms ±20 ms latency per direction, 1 % packet loss). "Before" is the original game or the version before the fix. Distances are game units; ships fly at about 4–6 units/s.
